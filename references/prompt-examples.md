# 按需使用的提示词示例

这是内容组织示例，不是固定场景模板或工具参数。保持用户要求，不为填满字段编造材质、尺寸、功能或人物。可用中文或英文，以表达明确为准。

## 产品图/使用场景的共用骨架

```text
用途：本次需要的产品静物、细节、使用场景或环境底图。
主体：具体产品/场景及本张要看清的内容。
输入角色：图1是本品外观依据；图2是相应部件依据；如使用摄影参考图，明确它只支持光影/材质气氛。只列实际提供的图片；纯环境任务无需产品参考。
构图与空间：有依据的产品角度、景别、主体和环境的前后关系；必要时的放置区或文字留白。
摄影：主光来源与软硬，环境补光和接触阴影；亮部保留真实材质，暗部层次可读，主体与环境光照一致。
材质：按本品实拍/资料描述实际材料、光泽及可见微纹理，不把所有产品统一做成哑光塑料。
产品保持项：本轮有关的轮廓、部件、接口、标识与固有色；动作涉及的握持/连接关系。
输出：当前画幅及背景要求；默认不添加叠加文字、标签、箭头、水印或装饰Logo；保留本品已有标识。
```

## 仅有场景需求

用户：“做一张室内餐厨场景底图，放在小家电海报里，横版，不要产品。”

可执行方向：明亮但有体积的真实餐厨摄影，按横幅组织台面与后景；为后续产品留出干净、合理承重的台面区域，记录计划的受光方向和视平线关系；家电产品不出现，不增加文字或人为标签框。无需索取某个家电的多视角，除非用户要精确匹配已选产品机位。

## 有真实产品的材质近景

用户：“用这张产品实拍做细节图，强调金属拉丝质感，不要字。”

以实拍为外形和材质依据，保留可见接缝、刻字与拉丝方向；选择能够读出表面加工的近景与相容侧光，反射克制且来自真实环境，避免把金属做成塑料。无新增宣传文字；不是要求删除原机身刻字。不要为了强化质感凭空加拉丝、划痕或厚度。

## 有保留要求的编辑

用户：“这张图的构图和产品我喜欢，背景偏暗，提亮一点。”

编辑目标是当前图片；修改目标为背景曝光及与之相应的自然环境补光，保持产品形体、标识、固有色、机位、人物动作与构图。不要把全部阴影拉平、让白色外壳过曝，或用全局滤镜改掉产品颜色。生成后比较产品是否漂移，暗部层次是否改善；不宣称保持项天然已锁定。

## 用户要求文字时

使用用户提供的准确文案，并根据本张构图安排可读位置；保留无字版作为已有版本，不为排字反复重画已通过的产品。工具支持精确图层时按实际字体/颜色/字号设置；只有生成位图时检查可见文字，明确不能证明精确字号或提供可编辑图层。遵循当前图像编辑工具约束，不为精确排版擅自改用未经请求的图像编辑路径。
